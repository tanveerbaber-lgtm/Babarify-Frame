# Babarify Frame 0.9.0 — first installable release (release candidate for the beta)

Babarify Frame is a free, privacy-focused media player for Windows 10 (1809) and 11, 64-bit.
Licensed under the GNU GPL v3 or later.

## Install

Run `BabarifyFrame-0.9.0-setup.exe`. It installs for your Windows user only (no administrator
rights) into `%LOCALAPPDATA%\Programs\Babarify Frame`. Options: a desktop shortcut, and adding
Babarify Frame to *Open with* for video and audio files (your default apps are not changed).

The installer is **not code-signed** yet, so Windows SmartScreen may say it does not recognise
the app: choose *More info → Run anyway* only if the file's SHA-256 matches the published
`SHA256SUMS.txt`:

    Get-FileHash .\BabarifyFrame-0.9.0-setup.exe -Algorithm SHA256

## Features

- **Playback** of common video and audio files (libVLC 3.0.24): hardware decoding, speed,
  frame stepping, A-B repeat, snapshots, fullscreen with auto-hiding controls.
- **Audio and subtitles:** track selection, external subtitle files, delays, subtitle look,
  preferred languages.
- **Picture and sound:** brightness, contrast, colour, aspect, crop, zoom, rotation, a 10-band
  equalizer with presets, saved profiles, optional volume boost.
- **Library and history:** folders you choose, thumbnails, search, playlists, resume where you
  stopped, *Continue watching*.
- **Network streams:** http/https (files, HLS, internet radio, playlists) and rtsp, fetched by
  Babarify itself with safe redirect and playlist handling.
- **Chapters, bookmarks, seek-bar previews and media information.**
- **Optional local AI (off by default):** subtitles generated from speech, and search of what
  is said, entirely on your PC.

Keyboard shortcuts: press F1 in the app.

## Updating and going back

Run a newer installer over the installed version: settings, library and everything else are
kept. To go back, run the older installer: it replaces the program the same way. Settings
written by a newer version are read (unknown options are ignored). If a newer version upgraded
the library database, an older version never changes it: it starts with an empty library and
says why, and the newer version finds everything intact when reinstalled.

## Uninstall

*Settings → Apps → Installed apps → Babarify Frame → Uninstall*. You are asked whether to
delete your Babarify data too (default: keep it). Your media files are never touched.

## Known limitations

See the milestone reports (`docs/milestones/`) for details. Most notable: no DVD/Blu-ray
playback; DASH streams are not supported; the alternate mpv engine is not included; previews
can be slow on 4K files; generated subtitles are a machine draft.

## Privacy

No account, no ads, no telemetry, no crash upload. See `PRIVACY.txt` in the program folder.
