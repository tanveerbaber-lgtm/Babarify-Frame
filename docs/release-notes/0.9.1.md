# Babarify Frame 0.9.1 — first public beta

Everything in [0.9.0](0.9.0.md), plus:

- **Help → Report a problem:** prepares the technical details for a problem report (version,
  Windows, engine, decoder, the open media's codecs, the last error). File names and log lines
  are included only if you tick them, your user folder is shown as `%USERPROFILE%`, and nothing
  is sent: copy the text into the issue form.
- **Easier to see controls:** text fields, lists, drop-downs, check boxes, buttons, sliders and
  scroll bars now have clearly visible outlines (WCAG 2.1 non-text contrast, at least 3:1).
- Beta feedback forms (problem report, feedback) and a private channel for security or privacy
  problems.

Installing, updating, going back, uninstalling and the privacy notice are unchanged from 0.9.0.
Known issues: `docs/beta/KNOWN_ISSUES.md`. Test scenarios: `docs/beta/TEST_SCENARIOS.md`.
