# Test corpus

All media is **synthetic**, generated by `tools/engine-benchmark/make_media.py` from FFmpeg's
`testsrc2` video and a −60 dB sine tone, so there are no copyright or provenance questions.
The files are git-ignored; regenerate them with:

```powershell
.\.venv\Scripts\python.exe tools\engine-benchmark\make_media.py
```

The machine-readable manifest is
[`tools/engine-benchmark/media-manifest.json`](../../tools/engine-benchmark/media-manifest.json):
for every file it records the exact FFmpeg command(s), the expected properties used by the
tests, the size and the SHA-256. Checksums are for ffmpeg version 9.0.2-full_build-www.gyan.dev;
other FFmpeg builds produce different bytes.

Sets: **benchmark** (M1 engine comparison), **corpus** (M2 common containers and codecs),
**edge** (M4 unusual, damaged and path edge cases), **failure** (invalid files).
Kinds: **valid** must play with the expected properties; **damaged** must not hang or crash
and the engine must play the next file; **invalid** must fail with a clear error.
