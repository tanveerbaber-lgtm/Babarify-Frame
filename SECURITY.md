# Security

Please report security or privacy problems privately, not in a public issue:
[open a private report](https://github.com/tanveerbaber-lgtm/Babarify-Media-Player/security/advisories/new).
A problem file or stream address helps, but leave out anything personal you don't need to share.

This is a free project with one maintainer, so no response time is promised.

| Version | Status |
|---|---|
| Windows 0.9.1 (public beta) | Fixes go into the next version |
| Android and iOS | Not released |

What the apps do and don't collect: [privacy notice](docs/PRIVACY.md).
